# 1

Простая видеотека для телевизора, телефона и компьютера.

## Как добавить видео

1. Поместите файл MP4 в папку `videos`.
2. Добавьте его в `videos.json`:

```json
[
  {
    "title": "Название ролика",
    "description": "Краткое описание",
    "src": "videos/video-01.mp4",
    "poster": "posters/video-01.jpg"
  }
]
```

Для лучшей совместимости с телевизорами используйте MP4 с видео H.264 и звуком AAC.
